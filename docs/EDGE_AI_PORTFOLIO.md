# 端侧 AI 作品集说明

## 现在能展示的工程能力

这个项目的亮点不是“温度计”，而是一条完整的非视觉端侧 AI 链路：

1. 传感器与实时采样：BMI088 SPI 双芯片协议、800 Hz 固定节拍、512 点窗口。
2. 信号处理：时域、角速度、Goertzel 频点和温度上下文，共 26 维特征。
3. 模型部署：无权重时一类异常检测，有权重时五分类推理；均完全离线。
4. 人机界面：MIPI DSI + GLCDC + 外部 SDRAM，以及显式 UI 状态机。
5. 工程可靠性：告警迟滞、传感器故障状态、事件环形缓冲。
6. 可观测性：DWT 推理耗时、置信度、模型版本、数据协议版本和 Top-3 解释。

简历可写成：

> 基于 Cortex-M85 RA8D1 与 BMI088 实现 800 Hz 振动/温度融合端侧故障诊断；完成 512 点实时特征流水线、一类异常与五分类模型部署、MIPI DSI 可视化，并加入微秒级推理剖析、告警迟滞和异常特征解释。

## 面试演示顺序

1. 上电展示无网络启动、自检和四个页面。
2. 正常工况长按 S1 校准，说明现场域适配的意义。
3. 串口执行 `m`，展示波形、分数、推理耗时和事件状态。
4. 安全地改变传感器固定方式或用低风险振动源产生分布变化，展示连续 3 帧确认、连续 5 帧恢复。
5. 执行 `i`，解释 Top-3 特征和模型/协议版本如何帮助调试与追踪。

演示时同时保存串口日志和手机录像。作品集应包含接线图、系统框图、混淆矩阵、推理耗时统计（P50/P95/最大值）、Flash/RAM 占用以及至少三种工况的实测结果。

## 下一步最值得做

### 1. int8 量化与 CMSIS-NN

收集完真实五分类数据后，使用训练后量化或量化感知训练导出 int8 权重，接入 CMSIS-NN。对比浮点与 int8 的准确率、Flash、RAM、平均/P95 推理耗时和单次能耗。RA8D1 的 Cortex-M85 Helium/MVE 与 CMSIS-NN 路线比只展示一个浮点模型更有岗位价值。

### 2. 标准化验证

- 按设备或采集日期划分训练/验证/测试集，避免相邻窗口泄漏。
- 输出混淆矩阵、每类 precision/recall/F1 和未知工况的误报率。
- 记录不同转速、负载、温度、安装位置下的域偏移。
- 为阈值、迟滞窗口和传感器掉线添加主机端单元测试。

### 3. 数据与模型生命周期

- 在模型头中加入训练数据版本、归一化参数校验和 CRC。
- 定义可回放的二进制遥测格式，配套 Python 可视化工具。
- 增加双分区模型或安全回滚，再讨论 OTA；不要先做无法验证的“云平台”。
