# BMI088 振动端侧 AI 运行指南

## 1. 硬件连接

1. 将 CPKCOR-RA8D1B 核心板装到 CPKEXP-EKRA8X1 扩展板，确认 256×480 MIPI 屏排线方向正确。
2. BMI088 只使用 3.3 V 逻辑并与扩展板共地。
3. SPI1：SCK→D13/P412，MISO→D12/P410，MOSI→D11/P411。
4. 片选：ACC_CS→D8/P504，GYRO_CS→D3/P907。不要把 GYRO_CS 接回 D9/PA07，因为显示所需 SDRAM 已占用该引脚。
5. 上位机串口：USB 转串口 RXD→D1/P409，TXD→D0/P408，GND→GND；不要连接转串口模块的 VCC。

## 2. 编译和下载

1. 启动 e² studio 2025-12（FSP 6.4.0），导入工程目录 `C:\Users\34542\Desktop\端侧AI与车辆嵌入式项目\ra8d1_bmi088_vibration_ai`。
2. 选择 `Debug` 配置并执行 **Project > Build Project**。工程使用 LLVM for Arm 21.1.1。
3. 连接调试器，下载 `Debug/ra8d1_bmi088_vibration_ai.elf` 后运行。
4. 本次只修改了用户源码；不要手工编辑 `ra/`、`ra_cfg/`、`ra_gen/`。仅在修改 FSP 外设/引脚时打开 `configuration.xml` 重新生成。

## 3. 首次上电

串口设置为 `115200-8-N-1`。可直接使用板载 J-Link OB 的 `COM16`，无需外接 USB-UART。应看到 `PROTO`、`DISPLAY`、`BMI088` 和 `MODEL` 启动记录。未接 BMI088 时，`BMI088,INIT,-3,...0x00` 与 `ERROR,BMI088_INIT,...` 是预期结果，屏幕会进入传感器故障保护页；接好模块后再按以下步骤校准。屏幕显示总览页后：

1. 短按扩展板 S1，确认总览、波形、AI 诊断、事件记录四页依次切换。
2. 让被测对象保持稳定且正常，长按 S1 至少 0.8 秒；校准 16 个窗口约需 10.2 秒。
3. 校准完成后在串口发送单字节 `m` 开启连续监测；再发一次 `m` 停止。
4. 上位机每约 500 ms 发送单字节 `q` 获取缓存快照，不会额外触发采样或推理。

## 4. 界面含义

- `BASELINE REQUIRED`：还没有一类异常检测基线，需要长按 S1 校准。
- `CALIBRATION FAILED`：校准期间读取传感器失败，需要检查接线并重新上电。
- `SENSOR` / `BMI088 SENSOR ERROR`：BMI088 初始化或采样失败。
- `ANOMALY ONLY` / `ONE-CLASS FALLBACK`：尚未导入五分类权重，当前运行现场校准的一类异常检测，这是预期状态。
- `WARN` / `ALARM`：经过 3 个异常窗口确认、5 个正常窗口恢复的迟滞状态，不等于单个采样点越限。

板载轻量渲染器仅包含 ASCII 5×7 字库，所以板上使用清晰英文缩写；中文图形化界面在 PC 上位机中显示。要在板载屏加入中文，必须引入有授权的中文字库和 UTF-8 解码。

## 5. 实板验收清单

- 屏幕无撕裂、四页切换正常，连续运行时不闪屏。
- 启动记录中 `DISPLAY,...,READY`；接入 BMI088 后芯片 ID 应为加速度 `0x1E`、陀螺仪 `0x0F`。未接模块时记录 `INIT,-3`/`0x00` 属于预期保护状态。
- 正常工况校准完整通过；静止、转速变化和轻微扰动时波形变化合理。
- 上位机能自动识别 `RA8D1_BMI088_EDGE_AI`，温度、波形、分数和 Top-3 解释同步更新。
- 正式展示前用真实机器重新采集正常基线；不要直接把实验台阈值用于安全保护。
